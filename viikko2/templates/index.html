Week 2: Python Web App

Flask + Gunicorn + MySQL behind Nginx on CSC cPouta.

Visitor Counter

Page loads: {{ visits }}

Every page load increases the count by one.

How It Works

Nginx listens on port 80 and forwards requests for the /viikko2/ path to the Python application as a reverse proxy. The application runs on Gunicorn at 127.0.0.1:5000, so its port is not exposed to the internet for all. The application is a systemd service that starts automatically when the server boots.

Counter Storage

The database is MySQL 8.0, running on the same server. The counter is stored in the counter table of the viikko2 database, which has a single row. Every page load runs UPDATE counter SET visits = visits + 1 and then reads the new value. Because the value is stored in the database rather than in the application's memory, it persists even if the application or the whole server is restarted.
